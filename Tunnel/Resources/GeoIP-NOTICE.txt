This product includes GeoLite2 data created by MaxMind, available from
https://www.maxmind.com/.

The geoip-cn.srs rules used by Byway are generated by SagerNet/sing-geoip
from Dreamacro/maxmind-geoip. Source and license information:
https://github.com/SagerNet/sing-geoip
https://github.com/Dreamacro/maxmind-geoip
https://www.maxmind.com/en/geolite/eula

Download the rule file from upstream and verify its SHA-256:
https://raw.githubusercontent.com/SagerNet/sing-geoip/66c864fcfe1535549e0658569cb514dbd35756ba/geoip-cn.srs

On Mac, save it to ~/Library/Application Support/Byway/geoip-cn.srs
to use routing configurations that contain GEOIP,CN.
For iOS or Windows source builds, save it to Tunnel/Resources/geoip-cn.srs.
